    Geometry Aware Operator Transformer (GAOT)¤

    neojax.models.gaot.GAOT ¤

    Geometry Aware Operator Transformer (GAOT).

    GAOT learns a map between functions given on arbitrary point clouds or meshes in \(d\) dimensions. It consists of

    1. a lifting PointwiseMLP of the input channels,
    2. a MAGNOBlock (encoder) that maps the function from the mesh to the points of a regular latent grid,
    3. a PointwiseMLP on the patches of the latent grid (patchify) with the positional encoding of the patches, absolute (sinusoidal) or rotary,
    4. a UViT transformer over the patches, unpatchified to the latent grid again,
    5. a MAGNOBlock (decoder) that maps the latent function to the output queries,
    6. a projection PointwiseMLP to the output channels.

    The MAGNOBlocks are multiscale attentional graph neural operators with a geometry embedding of the neighborhoods.

    For a fixed geometry, precompute the neighbors once with build_neighbors and pass them with in_neighbors and out_neighbors.

    Internal Attributes

    These fields store the internal layers state (and weights).

    • lifting (PointwiseMLP): Lifts the input channels to lifting_channels.
    • encoder (MAGNOBlock): Maps the mesh to the latent grid.
    • patch_linear (PointwiseMLP): Linear layer on the tokens of the patches.
    • pos_embedding (SinusoidalEmbedding | None): Absolute positional encoding of the patches.
    • processor (UViT): The transformer on the patches of the latent grid.
    • decoder (MAGNOBlock): Maps the latent grid to the queries.
    • projection (PointwiseMLP): Projects to out_channels.
    • in_channels (int): Number of channels of the input function.
    • out_channels (int): Number of channels of the output function.
    • lifting_channels (int): Number of channels of the latent function.
    • latent_resolution (tuple[int, ...]): Points of the latent grid per axis.
    • domain_bounds (tuple[tuple[float, float], ...] | None): Bounds of the domain.
    • patch_size (int): Latent grid points per axis of a patch.
    • positional_embedding (Literal["absolute", "rope"]): Positional encoding of the patches.

    Normalize the coordinates

    The latent grid is on \([-1, 1]^d\) and the radii of the MAGNOBlocks are in these units. The cosine attention depends on the origin of the coordinates. Either pass coordinates in \([-1, 1]^d\) or the domain_bounds of the coordinates. The rescaling is per axis, which does not preserve the aspect ratio of the domain (as in the reference implementation).

    Neighbor truncation

    The MAGNOBlocks consider at most max_neighbors neighbors per query and scale (the nearest ones), silently. Check with neighbor_truncation and choose max_neighbors large enough for your point densities, radii and scales.

    Differences to the reference implementation

    • The neighbors are padded fixed-width lists instead of ragged lists (CSR), to be compatible with jax.jit.
    • The random neighbor sampling is called edge_drop_strategy and max_neighbors is the width of the neighbor lists.
    • The learned scale weights of the MAGNOBlocks act on the rescaled coordinates, also with node_embedding.
    • The time-conditional normalization and the autoregressive rollout of the reference are not part of the model.

    Examples:

    import jax
import jax.numpy as jnp
import jax.random as jr
from neojax.models import GAOT

key = jr.key(0)
model_key, data_key = jr.split(key)
model = GAOT(
    key=model_key,
    in_channels=2,
    out_channels=1,
    latent_resolution=(16, 16),
    patch_size=2,
    lifting_channels=8,
    hidden_channels=32,
    n_heads=4,
    radius=0.2,
)
x_in = jr.uniform(data_key, (500, 2), minval=-1.0, maxval=1.0)
u = jnp.ones((4, 2, 500))  # batch of 4 functions on the same mesh
out = jax.vmap(lambda u: model(u, x_in=x_in, inference=True))(u)
